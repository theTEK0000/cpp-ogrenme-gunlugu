# Gün 1: main Fonksiyonu

Bugün öğrendiklerim:
- `main`, her C++ programının başlangıç noktası. Program çalışınca ilk o çağrılır.
- `int main()` sonunda bir sayı döndürür. `return 0` "hatasız bitti" anlamına gelir.
- `#include <iostream>` ile ekrana yazdırma araçlarını dahil ettim.
- Her komut `;` ile biter.

```cpp
#include <iostream>

int main() {
    std::cout << "Merhaba Dunya!" << std::endl;
    return 0;
}
```
